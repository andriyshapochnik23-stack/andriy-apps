# andriy-apps

Готові збірки (APK) моїх Android-додатків і маніфест для вбудованого оновлювача.
Тут лише APK та `index.json` — без вихідного коду, ключів і паролів.

| Додаток | Пакет |
|---|---|
| Світло — графіки відключень Черкасиобленерго | `ua.andriy.svitlo` |
| Пульт — керування ПК у домашній мережі | `ua.andriy.pult` |
| Будильник — за графіком змін | `ua.andriy.budylnyk` |
| Точки — іконки (набір іконок у стилі Nothing) | `ua.andriy.dots.icons` |

- Маніфест: `https://raw.githubusercontent.com/andriyshapochnik23-stack/andriy-apps/main/index.json`
- APK: у [Releases](https://github.com/andriyshapochnik23-stack/andriy-apps/releases), тег `<додаток>-<версія>`.

Оновлення в додатку: Опції → Оновлення → «Перевірити».
